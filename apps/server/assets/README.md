# Optional report branding

Reports render without brand images. Operators who have permission to use the
marks may supply `ucm-mark.png`, `ucm-mark-only.png`, and
`formula-sae-australasia-logo.jpg` here before building. The files are ignored
by Git and excluded from public source exports. Missing images leave the
corresponding layout area empty; report content and evidence remain intact.

These marks are not licensed by the source-code license. Do not redistribute
images or Docker bundles containing them without the appropriate permission.
